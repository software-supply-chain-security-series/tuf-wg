# The Update Framework Working Group

This is the Software Supply Chain Security Series working group that works to push standards for the [TUF (The Update Framework) project](https://github.com/theupdateframework).

Note that this working group consists of the same personnel as the TUF specification's leadership, namely [the TAP Editors](https://github.com/theupdateframework/specification/blob/master/MAINTAINERS.md).

Please refer all broader discussion about the standards, the standardization process, implementations of the project, adopters, and other concerns to the TUF project.  You can find more information on the project website:
https://theupdateframework.io/

Organizations who would like to support the Working Group are encouraged to join the [Software Supply Chain Security Series](https://join.sscss.io).
